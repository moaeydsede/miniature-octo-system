# نظام إدارة الدوام والرواتب – نسخة ويب (Frontend فقط)

✅ يعمل بدون سيرفر – مناسب للرفع على GitHub Pages.

## الملفات
- index.html : صفحة الدخول
- admin.html : لوحة الإدارة (Admin)
- manager.html : لوحة المدير (Manager)
- employee.html : بوابة الموظف (عرض فقط)
- README.md

## بيانات الدخول
- Admin: admin / admin123
- Manager: يتم إنشاؤه من لوحة Admin
- Employee: يدخل باسم الموظف فقط (كما هو مسجّل)

## أهم النقاط
- صك قبض احترافي للطباعة/حفظ PDF.
- إذا لم يداوم الموظف ولا يوم خلال الشهر ➜ المستحق النهائي = 0.
- الغياب بدون عذر يُحسب تلقائيًا عند عدم وجود سجل لهذا اليوم (ويمكن ضبط معامل الغياب بدون عذر من إعدادات الشهر).
- التقرير الشهري للإدارة مع إجمالي المستحقات + تصدير CSV.
- شاشة الدخول لا تعرض أي “ملاحظات” أو تلميحات.

## تشغيل
ارفع الملفات على GitHub Repository ثم فعّل GitHub Pages من Settings.
