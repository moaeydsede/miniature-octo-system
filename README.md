# نظام إدارة الدوام والرواتب – نسخة ويب (Frontend فقط)

✅ يعمل بدون سيرفر – مجاني بالكامل – مناسب للموبايل – للنشر على GitHub Pages.

## بيانات الدخول
- Admin (ثابت):  
  **username:** admin  
  **password:** admin123

- Manager: يتم إنشاؤه من Admin داخل النظام.
- Employee: دخول باسم الموظف فقط (عرض فقط).

## ملاحظة الأمان (حسب طلبك)
- الموظف **لا يرى ملاحظات الدوام** نهائياً.
- ملف مزامنة الموظفين **لا يحتوي على الملاحظات** ولا أي بيانات تعريفية للإدارة.

## طريقة التشغيل محلياً
افتح الملف:
- `index.html`

## النشر على GitHub Pages
1) أنشئ Repository جديد على GitHub.  
2) ارفع محتويات هذا المشروع (فك الضغط ثم ارفع الملفات).  
3) من Settings → Pages:
   - Source: Deploy from a branch
   - Branch: main / root
4) سيظهر رابط مباشر.

## التخزين
- LocalStorage داخل المتصفح.
- يمكنك التصدير/الاستيراد:
  - JSON (مزامنة)
  - XLSX (Excel)

> ملاحظة: مكتبات PDF و Excel تُحمّل من CDN (مجاناً) – لأول مرة تحتاج إنترنت لتحميلها، وبعدها تعمل عادة من الكاش.
